# Экзамен по React

Решения пяти практических работ по React. В коде прокомментирована каждая строка.

## Что внутри

- `react-ekzamen/` — проект со всеми работами. Слева меню для выбора задачи, справа сама задача.
- `Шпаргалка_React.docx` — шпаргалка: как всё работает, где хранятся счётчики, вопросы преподавателя с ответами.

| Папка | Работа |
|---|---|
| `src/1_nachalo` | Начало работы с React: счётчик, список дел, useEffect |
| `src/2_schetchik` | Счётчик React, задачи 1–6 |
| `src/3_recepty` | React Рецепты, задачи 1–5 |
| `src/4_bar` | Бар (классовые компоненты): теория и задачи 1–9 |
| `src/5_routing` | Роутинг в React, задачи 1–10 |

## Как запустить

Нужен [Node.js](https://nodejs.org/).

```bash
cd react-ekzamen
npm install
npm start
```

Откроется браузер с приложением. В Rider можно просто выбрать конфигурацию **start** и нажать ▶.
